# REST API Specification

Base URL: `http://localhost:8000/api`  
Interactive OpenAPI Documentation: `http://localhost:8000/docs`

---

## 1. Authentication Endpoints

### Register User
- **POST** `/auth/register`
- **Request Body**:
  ```json
  {
    "name": "Akash Sharma",
    "email": "candidate@example.com",
    "password": "Password@123",
    "confirm_password": "Password@123",
    "role": "CANDIDATE" // or "RECRUITER"
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "token_type": "bearer",
    "user": {
      "id": 1,
      "name": "Akash Sharma",
      "email": "candidate@example.com",
      "role": "CANDIDATE",
      "created_at": "2026-09-25T14:30:00Z"
    }
  }
  ```

### Login User
- **POST** `/auth/login`
- **Request Body**:
  ```json
  {
    "email": "candidate@example.com",
    "password": "Password@123"
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "access_token": "eyJhbGciOi...",
    "token_type": "bearer",
    "user": { ... }
  }
  ```

### Current User Profile
- **GET** `/auth/me`
- **Headers**: `Authorization: Bearer <JWT>`
- **Response** (`200 OK`): Returns current authenticated `UserResponse`.

## 2. Resumes Endpoints

### Upload Resume PDF
- **POST** `/resumes/upload`
- **Headers**: `Authorization: Bearer <JWT>`, `Content-Type: multipart/form-data`
- **Body**: `file`: PDF file stream
- **Validation**: `.pdf` extension, MIME check, max 10MB limit.
- **Response** (`201 Created`):
  ```json
  {
    "id": 1,
    "user_id": 2,
    "filename": "resume_akash.pdf",
    "file_size": 15420,
    "uploaded_at": "2026-09-25T14:35:00Z",
    "skills_count": 10,
    "extracted_text": "...",
    "clean_text": "...",
    "skills": [
      { "id": 1, "skill_name": "Python", "category": "Programming Languages" }
    ]
  }
  ```

### List Resumes
- **GET** `/resumes`
- **Headers**: `Authorization: Bearer <JWT>`
- **Behavior**: Candidates see their own uploaded resumes; Recruiters see all candidate resumes.

### Get Resume Details
- **GET** `/resumes/{id}`
- **Headers**: `Authorization: Bearer <JWT>`
- **Security**: 403 Forbidden if accessed by another candidate.

### Download Resume PDF
- **GET** `/resumes/{id}/file`
- **Headers**: `Authorization: Bearer <JWT>`
- **Response**: `application/pdf` binary stream.

### Delete Resume
- **DELETE** `/resumes/{id}`
- **Headers**: `Authorization: Bearer <JWT>`
- **Response**: `204 No Content`.

## 3. Jobs Endpoints

### Create Job Posting
- **POST** `/jobs`
- **Headers**: `Authorization: Bearer <JWT>` (Recruiter only)
- **Request Body**:
  ```json
  {
    "title": "Python Machine Learning Intern",
    "company": "Apex AI",
    "description": "Building NLP and machine learning models...",
    "experience_level": "Internship",
    "required_skills": ["Python", "SQL", "Machine Learning"],
    "preferred_skills": ["FastAPI", "Git"]
  }
  ```
- **Response** (`201 Created`): Returns created `JobOut`.

### List Job Postings
- **GET** `/jobs`
- **Query Params**: `skip` (default 0), `limit` (default 100).
- **Response** (`200 OK`): Array of active `JobOut` items.

### Get Job Details
- **GET** `/jobs/{id}`
- **Response** (`200 OK`): Job specifications, required skills, preferred skills, analysis count.

### Update Job Posting
- **PUT** `/jobs/{id}`
- **Headers**: `Authorization: Bearer <JWT>` (Posting recruiter only).

### Delete Job Posting
- **DELETE** `/jobs/{id}`
- **Headers**: `Authorization: Bearer <JWT>` (Posting recruiter only).

## 4. Match Analysis & Skill Gap Endpoints

### Execute Match Analysis
- **POST** `/analysis`
- **Headers**: `Authorization: Bearer <JWT>`
- **Request Body**:
  ```json
  {
    "resume_id": 1,
    "job_id": 2
    // Or for custom pasted jobs:
    // "custom_job_title": "ML Intern",
    // "custom_company": "Tech Corp",
    // "custom_job_description": "We need Python and SQL..."
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "id": 1,
    "resume_id": 1,
    "job_id": 2,
    "candidate_name": "Akash Sharma",
    "job_title": "Python Machine Learning Intern",
    "company": "Apex AI",
    "similarity_score": 72.5,
    "skill_match_percentage": 60.0,
    "matched_skill_count": 3,
    "required_skill_count": 5,
    "matched_skills": ["Python", "SQL", "Git"],
    "missing_skills": ["Machine Learning", "Scikit-learn"],
    "additional_skills": ["Java", "React"],
    "learning_recommendations": [
      {
        "skill": "Machine Learning",
        "title": "Machine Learning Fundamentals",
        "description": "Study supervised and unsupervised learning algorithms...",
        "resource": "https://scikit-learn.org/stable/tutorial/index.html"
      }
    ],
    "metric_disclaimer": "This Job Match Score is an automated text and skill similarity metric generated by the platform. It does not represent hiring probability or guarantee employment selection."
  }
  ```

### Analysis History
- **GET** `/analysis/history`
- **Response** (`200 OK`): List of recent analysis records.

### Job Candidate Analyses
- **GET** `/analysis/job/{job_id}`
- **Headers**: `Authorization: Bearer <JWT>` (Recruiter only).
- **Response** (`200 OK`): All candidate matches evaluated for the specified job.

### Batch Candidate Evaluation
- **POST** `/analysis/batch/{job_id}`
- **Headers**: `Authorization: Bearer <JWT>` (Recruiter only).
- **Request Body**: `[1, 2, 3]` (Array of resume IDs).
- **Response** (`200 OK`): Array of evaluated `AnalysisDetailOut` objects.

### Side-by-Side Candidate Comparison
- **POST** `/analysis/compare`
- **Request Body**: `[1, 2]` (Array of analysis IDs).
- **Response** (`200 OK`): Array of comparative candidate records for matrix display.

## 5. Dashboard Endpoints

### Candidate Dashboard Summary
- **GET** `/dashboard/candidate`
- **Headers**: `Authorization: Bearer <JWT>` (Candidate).
- **Response** (`200 OK`): Total resumes, active resume info, detected skills count, total analyses, recent job matches.

### Recruiter Dashboard Summary
- **GET** `/dashboard/recruiter`
- **Headers**: `Authorization: Bearer <JWT>` (Recruiter).
- **Response** (`200 OK`): Total jobs, candidate pool count, total analyses, average similarity score, distribution charts data, recent candidates table.
